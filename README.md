# Sistema Acadêmico DSII

Projeto integrador da disciplina Desenvolvimento para Servidores II.

## Objetivo

Desenvolver gradualmente uma aplicação web para cadastro de alunos, disciplinas, usuários e lançamento de notas.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL
- JWT
- Git e Github

## Estrutura
- frontend: interface da aplicação
- backend: API e regras do servidor
- database: scripts do banco de dados
- docs: documentação e evidências

## Instruções:
- use `npm install` para instalar as dependências;
- use `cd backend` e depois `npm run dev` para rodar o servidor localmente;
- baixe e instale a extensão 'live-server' para rodar o frontend;
